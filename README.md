# Muneeswaran — Developer Portfolio

A futuristic, responsive developer portfolio built with React, Vite, Framer Motion, and Lucide icons.

## Features
- Responsive desktop and mobile layouts
- Dark glassmorphism UI with orange/purple accents
- Animated hero illustration (CSS 3D-style laptop; no heavy 3D scene required)
- Scroll reveal animations
- Sections: about, toolkit, GoAurex services and MailVerifyPro, projects, experience, contact
- Content based on the Muneeswaran Professional and Company Report
- Accessible navigation and reduced-motion support

## Run locally
1. Install Node.js 20 or newer.
2. Open this project folder in a terminal.
3. Install packages:
   ```bash
   npm install
   ```
4. Start development:
   ```bash
   npm run dev
   ```
5. Build for production:
   ```bash
   npm run build
   ```

## Personalize before publishing
- Update the email address `hello@goaurex.com` if you prefer another contact.
- Confirm profile statistics and experience dates.
- Update project links to direct repositories when ready.
- Add a real resume file and point the hero button to it if you want a download CTA.
- Replace any portfolio project summaries with accurate descriptions of the public repositories.

## Deploy
Push the project to GitHub and import the repository into Vercel, or build with `npm run build` and deploy the `dist` folder to any static hosting provider.
